# Quizmo

[Quizmo](https://quizmo.fun/) is a fast-paced daily quiz with ten questions, ten seconds per question and answers ranging from 1 to 25. The challenge is simple: find the right number before time runs out.

Choose from four layouts: a 5×5 grid, a pyramid, a daily random layout or a super-random layout that changes with every question. Faster answers earn more points, while the less predictable layouts offer score bonuses.

Everyone receives a fresh set of questions each day and can play one layout, making scores easy to compare without demanding endless play.

[Play Quizmo](https://quizmo.fun/).
